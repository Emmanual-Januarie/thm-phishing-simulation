# TryHackMe - Phishing Investigation

## Overview
This repository contains documented phishing investigations conducted through TryHachMe SOC Simulations

Each case includes investigation report, supporting evidence, analysis, findings, and recommended remediation.

## Objectives
- Investigate suspicious inbound emails
- Investigate Firewall Communication attempts
- Correlate firewall, email, and SIEM events
- Determine appropiate incident verdicts

## Tools Used
- Splunk (Provided by TryHackMe)
- TryHackMe Reputation Checker

## Investigation Methodology
Each investigation follows a consistent process:
1. Alert identification and triage
2. Evidence Collection
3. Investigation findings
4. Verdict and Escalation conclusion
5. Remediation recommendations
